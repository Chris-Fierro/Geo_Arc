       Definir en el plugin `overpassProxyPlugin` la constante `const MAX_BODY_SIZE = 64 * 1024;` (64 KB).

    2. **Guardián de streaming en el listener 'data':**
       Inicializar variables de control de flujo antes de escuchar eventos: `let body = '';`, `let bodyLength = 0;`, `let isOverLimit = false;`.
       En el callback de `req.on('data', (chunk: any) => { ... })`:
       - Si `isOverLimit` es verdadero, retornar de inmediato ignorando fragmentos posteriores.
       - Incrementar `bodyLength += chunk.length;`.
       - Si `bodyLength > MAX_BODY_SIZE`, establecer `isOverLimit = true;`, asignar `res.statusCode = 413;`, configurar cabecera `'Content-Type': 'application/json'`, enviar `res.end(JSON.stringify({ error: 'Payload Too Large: La consulta Overpass excede el límite máximo permitido de 64 KB.' }))`, y destruir el socket entrante invocando `req.destroy();` para abortar la recepción.
       - En caso contrario, acumular `body += chunk.toString();`.

    3. **Protección en el listener 'end':**
       Al inicio del callback de `req.on('end', async () => { ... })`:
       - Verificar `if (isOverLimit) return;` para evitar cualquier procesamiento o solicitud upstream si ya se abortó la conexión.

    4. **Cabecera User-Agent legítima:**
       En la llamada `fetch(endpoint, ...)` dentro de `fetchFromEndpoint`:
       - Actualizar la cabecera `'User-Agent'` asignándole el valor `'GeoArc/1.4 (Architectural SIG Assistant)'`.

    5. **Remoción de GEMINI_API_KEY en directiva define:**
       En la configuración exportada con `defineConfig(({mode}) => { ... })`:
