    1. **Constantes del elipsoide WGS84 y factor de escala UTM:**
       - `WGS84_A = 6378137.0` (semieje mayor en metros)
       - `WGS84_F = 1 / 298.257223563` (aplanamiento)
       - `E2 = WGS84_F * (2 - WGS84_F)` (~0.00669437999014)
       - `EP2 = E2 / (1 - E2)` (~0.00673949674228)
       - `K0 = 0.9996` (factor de escala central UTM)

    2. **Catálogo de sistemas de referencia soportados (`SUPPORTED_CRS`):**
       Exportar la interfaz `CrsDefinition` y el diccionario `SUPPORTED_CRS`:
       - `EPSG:32718`: `{ code: 'EPSG:32718', name: 'WGS 84 / UTM Zona 18S (Chile Costa / Sur)', isProjected: true, utmZone: 18, isSouth: true }`
       - `EPSG:32719`: `{ code: 'EPSG:32719', name: 'WGS 84 / UTM Zona 19S (Chile Centro / Santiago)', isProjected: true, utmZone: 19, isSouth: true }`
       - `EPSG:32633`: `{ code: 'EPSG:32633', name: 'WGS 84 / UTM Zona 33N (Referencia Proyectada)', isProjected: true, utmZone: 33, isSouth: false }`
       - `EPSG:4326`: `{ code: 'EPSG:4326', name: 'WGS 84 Geográficas (Latitud / Longitud en Grados)', isProjected: false }`

    3. **Algoritmo de proyección directa `latLonToUtm` (Snyder 1987):**
       - Exportar `latLonToUtm(latDeg: number, lonDeg: number, zone: number, isSouth: boolean): { easting: number; northing: number }`.
       - Salvaguarda: acotar `latDeg` a `[-80, 84]` para prevenir divisiones por cero en los polos.
       - Calcular el meridiano central `lambda0 = ((zone - 1) * 6 - 180 + 3) * (Math.PI / 180)`.
       - Calcular la distancia de arco meridiano $M$ mediante la serie polinómica de Snyder (términos de $\phi$, $\sin(2\phi)$, $\sin(4\phi)$, $\sin(6\phi)$).
       - Calcular $N$, $T = \tan^2\phi$, $C = \eta'^2$, $A = \cos\phi \cdot (\lambda - \lambda_0)$.
       - Calcular `easting` con falso Este de `500000.0` metros:
         `easting = K0 * N * (A + (1 - T + C) * A^3 / 6 + (5 - 18*T + T^2 + 72*C - 58*EP2) * A^5 / 120) + 500000`.
       - Calcular `northing` con falso Norte de `10000000.0` metros si `isSouth === true`:
         `northing = K0 * (M + N * Math.tan(phi) * (A^2 / 2 + (5 - T + 9*C + 4*C^2) * A^4 / 24 + (61 - 58*T + T^2 + 600*C - 330*EP2) * A^6 / 720)) + (isSouth ? 10000000 : 0)`.

    4. **Función unificada `projectPointToCrs`:**
       - Exportar `projectPointToCrs(lat: number, lon: number, crsCode: string): { x: number; y: number }`.
       - Si `SUPPORTED_CRS[crsCode]?.isProjected` es `false` (o código `EPSG:4326`), retorna `{ x: lon, y: lat }`.
       - Si es proyectado, extrae `utmZone` e `isSouth` y retorna `{ x: utm.easting, y: utm.northing }`.

    5. **Generador de Worldfile `generateWorldFileForCrs`:**
       - Exportar `generateWorldFileForCrs(params: { bbox: { minLat: number; maxLat: number; minLon: number; maxLon: number }; width: number; height: number; crsCode: string }): string`.
       - Si `!isProjected`: genera la matriz de 6 líneas en grados decimales con 10 decimales (`xScale`, `0.0`, `0.0`, `-yScale`, `minLon + xScale/2`, `maxLat - yScale/2`).
       - Si `isProjected`: proyecta esquina noroeste `topLeft = projectPointToCrs(bbox.maxLat, bbox.minLon, crsCode)` y sureste `bottomRight = projectPointToCrs(bbox.minLat, bbox.maxLon, crsCode)`.
       - Calcula `xScale = Math.abs(bottomRight.x - topLeft.x) / width` y `yScale = Math.abs(topLeft.y - bottomRight.y) / height`.
       - Emite las 6 líneas separadas por `\r\n` con 6 decimales:
         Línea 1: `xScale.toFixed(6)` (tamaño del píxel en X)
         Línea 2: `'0.000000'` (rotación)
         Línea 3: `'0.000000'` (rotación)
         Línea 4: `(-yScale).toFixed(6)` (tamaño del píxel en Y, negativo)
         Línea 5: `(topLeft.x + xScale / 2).toFixed(6)` (coordenada X del centro del píxel superior izquierdo)
         Línea 6: `(topLeft.y - yScale / 2).toFixed(6)` (coordenada Y del centro del píxel superior izquierdo)
