| Token | Value | Usage |

- 40px: Floating HUD toolbar fixed width (`w-10` in `ContourViewer.tsx` zoom and export controls; 40px is an exact multiple of 4: 10 × 4px).

1. Reset lot polygon button ("Limpiar Lote")

## Visual Hierarchy & Focal Points

- **Primary Focal Point:** The centralized interactive 2.5D/3D viewport (`ContourViewer` / `ThreeTerrainViewer`), taking >70% of screen area with dark technical CAD aesthetics and ambient coordinate grid.
- **Secondary Focal Point:** The collapsible left sidebar (`380px` fixed width) structured into numbered vertical steps:
  - Step 1: `1. Selección de terreno` (OSM Satelital vs Malla 3D Local)
  - Step 2: `2. Parámetros de Extracción` (Modo, Curvas, CRS, OGUC, Solar)
- **Tertiary Floating HUD:** Right-aligned floating utility panels in `ContourViewer.tsx`:
  - Panel 1: Zoom controls (`ZoomIn`, `ZoomOut`, `Maximize` reset view)
  - Panel 2: Export actions (`DXF`, `STL`, and new `SVG` button)
- **Accessibility & Tooltip Fallback:** Every icon-only action (`Download`, `Upload`, `Maximize2`, `Sun`/`Moon`, `X`) MUST have an explicit `title` attribute and an accessible `aria-label` describing the action to screen readers.

## Detailed Interaction Contracts (CAD-04 & CAD-03)

### 1. Local 3D Mesh Upload Zone (`CAD-04` / `src/App.tsx`)

#### Placement
Located in the sidebar of `src/App.tsx` under Section 1 (`1. Selección de terreno`), organized with a segmented toggle:
- Tab 1: `Satelital OSM` (renders the existing `OsmImporter.tsx` component).
- Tab 2: `Malla 3D (.PLY / .FBX)` (renders the local mesh dropzone and processing status).

#### Visual & State Specifications
1. **Idle / Empty State:**
   - Container: Dashed border card (`border-dashed border-border-strong hover:border-accent bg-bg-elevated/40 p-4 rounded-sm text-center transition-colors cursor-pointer`).
   - Icon: `Upload` from `lucide-react` (size 20px, text-accent mb-2).
   - Primary text: "Arrastra tu malla 3D aquí" (12px, font-bold, text-text-main).
   - Secondary text: "Formatos: .PLY (Point Cloud / Mesh) o .FBX (ASCII / Binary) hasta 50MB" (10px, text-text-faded).
   - Button: "Seleccionar Archivo Local" (`bg-bg-surface border border-border-main hover:border-accent text-[10px] font-bold uppercase tracking-wider py-1.5 px-3 rounded-sm text-text-main mt-3`).
   - File input: Hidden `<input type="file" accept=".ply,.fbx" className="hidden" />`.
2. **In-Flight / Processing State:**
   - Replaces content with a centered pulsing spinner (`w-5 h-5 border-2 border-accent border-t-transparent rounded-full animate-spin`).
   - Status text: "Procesando geometría 3D y calculando cotas..." (10px font-mono text-accent uppercase tracking-widest mt-2).
3. **Populated / Success State:**
   - Displays a technical summary card:
     - Header: File name (`truncate`, 12px bold text-text-main) with green check badge (`✓ Malla 3D Activa`).
     - Grid metrics (10px monospace):
       - Vértices / Dimensiones: `{meshData.w.toFixed(1)}m × {meshData.h.toFixed(1)}m`
       - Rango de Elevación: `Min: {meshData.minEv.toFixed(1)}m | Max: {meshData.maxEv.toFixed(1)}m (Δ: {(meshData.maxEv - meshData.minEv).toFixed(1)}m)`
       - Grilla de interpolación: `{meshData.cols || 150} × {meshData.rows || 150} celdas`
     - Action buttons:
       - "Reemplazar Malla" (reopens file picker)
       - "Descartar Malla" (destructive action restoring default OSM state)
4. **Behavioral Contract:**
   - Triggers `processMeshFile(file, 150)` from `src/lib/meshProcessor.ts`.
   - On success: updates `meshData`, `fileName`, sets `isDone(true)`, resets `customLotPts`, and shifts `viewerMode` to `technical`.
   - On error: displays the error contract copy and restores idle dropzone state without unmounting the app.

### 2. Topographic SVG Vector Sheet Export Button (`CAD-04` / `src/components/ContourViewer.tsx`)

#### Placement
Integrated directly into the floating HUD export panel (`w-10` floating vertical toolbar) on the right edge of `ContourViewer.tsx`, immediately following the `DXF` and `STL` buttons. Also mirrored in the top navigation quick export bar of `src/App.tsx` when in technical viewer mode.

#### Visual Specifications
- **Button Structure in HUD:**
  ```tsx
  <div className="w-full h-[1px] bg-border-main"></div>
  <button
    onClick={handleExportSVG}
    className="py-2 text-text-faded hover:text-accent transition-colors flex flex-col items-center justify-center gap-1 cursor-pointer"
    title="Descargar Lámina Topográfica Vectorial (.SVG) con curvas de nivel, cotas métricas y capas activas"
    aria-label="Descargar Lámina Topográfica Vectorial en formato SVG"
  >
    <Download size={14} />
    <span className="text-[8px] font-bold tracking-widest uppercase">SVG</span>
  </button>
  ```
- **Export Trigger & Payload:**
  - Function: `handleExportSVG()` extracts the clean SVG DOM or generates the SVG XML string from `meshData` and active contours.
  - File Name: `topografia_${fileName.replace(/\.[^/.]+$/, "")}.svg`.
  - SVG Specs:
    - Root: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="..." width="100%" height="100%">`
    - Metadata Header: XML comments including CRS, bounding box coordinates, contour interval, minimum/maximum elevation, and generation timestamp.
    - Group `<g id="contour-lines">`: Master index curves with stroke width `1.5px` and standard curves with stroke width `0.75px`.
    - Group `<g id="contour-labels">`: Elevation text tags positioned along contours if `showContourLabels` is true.
    - Group `<g id="lot-boundary">`: Projected lot polygon with distinct dashed stroke if `customLotPts` exists.
    - Group `<g id="urban-context">`: Clipped roads and buildings if layers are visible.
  - Browser Action: Direct instant download via `triggerBrowserDownload(blob, filename)`.
