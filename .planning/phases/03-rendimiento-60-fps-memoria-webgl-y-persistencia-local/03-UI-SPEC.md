## Visual Hierarchy & Focal Points

- **Primary Focal Point:** The centralized interactive 2.5D/3D viewport (`ContourViewer` / `ThreeTerrainViewer`), taking >70% of screen area with dark technical CAD aesthetics, 60 FPS orbital fluidity, and ambient coordinate grid.
- **Secondary Focal Point:** The collapsible left sidebar (`380px` fixed width) structured into numbered vertical steps:
  - Step 1: `1. Selección de terreno` (OSM Satelital vs Malla 3D Local)
  - Step 2: `2. Parámetros de Extracción` (Modo, Curvas, CRS, OGUC, Solar)
  - Redundant simulation button ("Generar Visualización 3D") removed, allowing immediate visual inspection upon data arrival.
- **Tertiary Floating HUD & Header Controls:**
  - Top navigation bar hosts project branding, session controls ("Nueva Sesión", "Exportar", "Importar"), and theme toggle.
  - Floating utility panels in `ContourViewer.tsx` for zoom and direct CAD/vector exports (`DXF`, `STL`, `SVG`).
- **Overlay Toast & Modal Layer:**
  - **Session Restored Toast:** Discrete, non-blocking notification banner positioned at the top-right corner (`top-14 right-4 z-50`), auto-fading after 4000ms.
  - **Reset Confirmation Modal:** High-contrast modal dialog centered on screen with dark semi-transparent backdrop (`bg-black/60 backdrop-blur-xs`), requiring explicit confirmation before clearing project data.
- **Accessibility & Tooltip Fallback:** Every icon-only action (`RotateCcw`, `Download`, `Upload`, `Moon`/`Sun`, `X`, `Maximize2`) MUST have an explicit `title` attribute and an accessible `aria-label` describing the action to screen readers.

## Detailed Interaction Contracts (PERF-01 & PERF-04)

### 1. Control "Nueva Sesión" / "Restablecer Sesión" (`PERF-01` / `src/App.tsx`)

#### Placement
Located in the top navigation bar of `src/App.tsx`, grouped immediately before the `.geoarc` "Exportar" and "Importar" actions:
- Position: Header action strip (`div.flex.items-center.gap-3`).
- Replaces reliance on manual browser cache clearing with an explicit in-app session lifecycle control.

#### Visual Specifications
- **Button Structure in Header:**
  ```tsx
  <button
    onClick={() => setShowResetConfirm(true)}
    className="flex items-center gap-2 text-[10px] uppercase font-bold tracking-widest text-text-faded hover:text-accent transition-colors border border-border-main hover:border-accent bg-bg-surface px-3 py-1.5 rounded-sm cursor-pointer"
    title="Restablecer proyecto y limpiar almacenamiento local IndexedDB"
    aria-label="Restablecer sesión activa y comenzar nuevo proyecto"
  >
    <RotateCcw size={13} />
    <span>Nueva Sesión</span>
  </button>
  ```
- **Confirmation Modal Dialog:**
  - Triggered when `showResetConfirm === true`.
  - Backdrop: `fixed inset-0 z-50 bg-black/60 backdrop-blur-xs flex items-center justify-center p-4` (closes on `Escape` key).
  - Dialog Card: `bg-bg-surface border border-border-strong rounded-sm p-6 max-w-md w-full shadow-2xl space-y-4`.
  - Header:
    - Icon: `AlertTriangle` (`size={20}`, text-accent).
    - Title: "Restablecer Sesión de Trabajo" (14px, font-bold, text-text-main).
  - Body:
    - Text: "¿Deseas restablecer la sesión activa? Se eliminarán los datos temporales del terreno, cotas y polígonos almacenados en IndexedDB y se reiniciará el visor al estado base. Los archivos ya exportados (.geoarc, .DXF, .SVG) no se verán afectados." (12px, text-text-muted, leading-relaxed).
  - Action Footer:
    - Row container: `flex items-center justify-end gap-3 pt-2 border-t border-border-main`.
    - Cancel Button (Safe): "Conservar Sesión Actual" (`border border-border-main hover:border-border-strong bg-bg-elevated px-4 py-2 rounded-sm text-xs font-semibold text-text-main cursor-pointer`).
    - Confirm Button (Destructive): "Confirmar Restablecimiento" (`bg-red-600 hover:bg-red-700 text-white px-4 py-2 rounded-sm text-xs font-bold uppercase tracking-wider cursor-pointer transition-colors shadow-sm`).
- **Behavioral Contract:**
  - On confirm:
    1. Invokes `storageService.clearSession()`.
    2. Resets React state: `setMeshData(undefined)`, `setCustomLotPts(null)`, `setFileName('terreno_osm.json')`, `setIsDone(false)`, resets `ogucParams` and `solarParams` to defaults.
    3. Closes confirmation modal (`setShowResetConfirm(false)`).
    4. Viewport returns to clean initial state.

### 2. Toast de Notificación de Sesión Restaurada (`PERF-01` / `src/App.tsx`)

#### Placement
Floating non-modal banner in the top-right corner of the application window (`top-14 right-4 z-50`).

#### Visual & Behavioral Specifications
- **Container:**
  ```tsx
  <div
    role="status"
    aria-live="polite"
    className="flex items-start gap-3 p-3.5 bg-bg-surface/95 backdrop-blur-sm border border-green-500/30 rounded-sm shadow-xl max-w-sm animate-in fade-in slide-in-from-top-2 duration-300"

    <CheckCircle2 size={16} className="text-green-400 shrink-0 mt-0.5" />
    <div className="flex-1 min-w-0">
      <h4 className="text-xs font-bold text-text-main leading-tight">
        Sesión de trabajo restaurada
      </h4>
      <p className="text-[10px] text-text-faded leading-normal mt-1">
        Se recuperó el terreno y los parámetros previos desde el almacenamiento local IndexedDB.
      </p>
    </div>
    <button
      onClick={() => setShowRestoreToast(false)}
      className="text-text-subtle hover:text-text-main cursor-pointer p-0.5 rounded-xs transition-colors shrink-0"
      title="Cerrar notificación"
      aria-label="Cerrar Notificación"
    >
      <X size={13} />
    </button>
  </div>
  ```
- **Lifecycle & Dismissal:**
  - Appears only when `storageService.loadSession()` returns a populated project state upon initial mount (`useEffect`).
  - Auto-dismiss: Closes automatically after 4000ms (`setTimeout`).
  - Manual dismiss: Closes immediately when clicking the `X` button.
  - Does NOT show if `IndexedDB` was empty or if the user cleared the session.

### 3. Eliminación de Control Redundante "Generar Visualización 3D" (`PERF-04` / `src/App.tsx`)

#### Removal Specifications
- In `src/App.tsx`, lines 1131-1148 currently render a simulated generation button:
  ```tsx
  // REMOVE:
  <button
    onClick={handleSimulateProcess}
    disabled={isProcessing}
    className="mt-5 w-full py-2.5 bg-accent text-white ..."
  >
    ... Generar Visualización 3d
  </button>
  ```
- **Rationale:** Terrain data fetching in both OSM (`handleOsmDataFetched`) and local 3D mesh (`handleLocalMeshLoaded`) already populates `meshData` and marks `isDone(true)` upon completion. The simulated 600ms timeout button is redundant, causes user confusion, and delays inspection.
- **Resulting UI State:**
  - The sidebar ends cleanly at the terrain summary information and technical layer toggles.
  - As soon as terrain coordinates or local mesh files are loaded, the 2.5D/3D viewport renders immediately.
  - Removes unused states: `isProcessing`, `isProcessing3d`, and callback `handleSimulateProcess`.
